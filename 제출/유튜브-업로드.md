# 유튜브 업로드 안내

> 올릴 파일: `제출/영상/최종-미래톡-발표영상.mp4`
> 2분 58초 · 1280×720 · 7.6MB · h264 + aac
> **공개 범위는 반드시 "전체공개"** — 공고 요건입니다. 일부공개·비공개는 가산점 무효.

## 순서

1. **studio.youtube.com** 접속 (형 구글 계정으로 로그인)
2. 오른쪽 위 **만들기 → 동영상 업로드**
3. mp4 파일 끌어다 놓기
4. 아래 제목·설명 복사해서 붙여넣기
5. **"아니요, 아동용이 아닙니다"** 선택 ← 이거 안 하면 다음으로 못 넘어감
6. 다음 → 다음 → 다음 (동영상 요소·검토는 건너뛰어도 됨)
7. 공개 상태에서 **전체공개** 선택 → **게시**
8. 나온 URL 복사

가로형(16:9) 3분 미만이라 쇼츠가 아니라 일반 영상으로 올라갑니다. 그대로 두면 됩니다.
